# SUBCAST STUDIO

대본 기반 **TTS 음성 + 16:9 투명 배경(Alpha Channel) 자막 영상 자동 생성** 및 **Whisper AI 기반 영상 음성 인식(STT) 자막 추출** 로컬 스튜디오입니다.

---

## 비개발자용 원클릭 실행 방법 (Release 다운로드)

1. **[Releases 페이지](../../releases)에서 최신 압축 파일 다운로드 후 압축 해제**
   - **macOS (Apple Silicon 단독 실행 앱)**: `SUBCAST-STUDIO-v1.0.0-macOS-App.zip` 다운로드 → 압축 해제 후 **`SUBCAST STUDIO.app`** 또는 **`실행하기_Mac.command`** 더블클릭
   - **원클릭 실행 패키지 (Mac / Windows 공용)**: `SUBCAST-STUDIO-v1.0.0-QuickStart.zip` 다운로드 → 압축 해제 후:
     - **Mac**: `실행하기_Mac.command` 더블클릭
     - **Windows**: `실행하기_Windows.bat` 더블클릭
2. 실행되면 자동으로 브라우저에서 **`http://127.0.0.1:8765`** 스튜디오 화면이 열립니다.
   - *(Mac 최초 실행 시 "확인되지 않은 개발자" 안내가 뜨면 `우클릭 → 열기`를 눌러 실행해 주세요.)*

## 주요 기능

### 1. TTS 자막 영상 생성 (16:9 투명 알파 채널)
- **음성 모드 선택**:
  - **TTS 음성 생성**: `Typecast API`, `Edge Neural TTS (무료 고품질 한국어)`, `Local (오프라인 내장 음성)` 지원
  - **음성 없음 (기본 2.0초)**: 음성 없이 투명 자막 영상만 생성 (줄당 표시 시간 `0.8s ~ 8.0s` 조절 가능)
- **줄별 TTS 발화 대사 직접 수정**:
  - 화면에 표시될 자막과 실제 TTS가 읽을 대사를 분리하여 줄별로 직접 수정 가능
  - 숫자(`0-9`) 및 특수문자 자동 읽기 제외 필터 지원
- **커스텀 자막 디자인 & 실시간 16:9 미리보기**:
  - `.ttf` / `.otf` 커스텀 폰트 업로드, 글자 크기/수직 위치, 글자색/외곽선 두께, 드롭 섀도우(색상/투명도/X·Y 거리/블러), 배경 박스 설정
- **통합 영상 + 줄별(Enter 기준) 개별 클립 분리 다운로드**:
  - 전체 합본 영상(`.mov` Apple ProRes 4444 Alpha / `.webm` VP9 Alpha) + `.wav` + `.srt`
  - **Enter 줄바꿈 기준** 줄별 개별 음성(`.wav`) · 투명 자막 영상(`.mov`, `.webm`) · 자막 이미지(`.png`) 개별 다운로드 및 전체 `.zip` 일괄 다운로드

### 2. 영상 자막 추출 (Whisper STT)
- 영상/오디오 파일을 드래그 앤 드롭하면 로컬 `faster-whisper` 엔진으로 타임스탬프 자막 자동 추출
- 구간별 시간 및 텍스트 인라인 편집, `.srt` / `.vtt` / `.txt` 다운로드, **TTS 대본으로 원클릭 전송**
